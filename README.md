# muak-os/catalog

Release catalog **data** repository for [Muak](https://github.com/muak-os/muak):
the digest-pinned documents that map a release line to its payload images.

| Kind | Document | Published image |
|---|---|---|
| core | `core/<release>.toml` | `core:<release>` |
| overlays | `overlays/<release>.toml` | `overlays:<release>` |
| extensions | `extensions/<release>.toml` | `extensions:<release>` |
